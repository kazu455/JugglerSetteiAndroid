# ジャグラー設定判別 (Android / Kotlin + Jetpack Compose)

現行ジャグラーシリーズ主要機種の実戦データ（総回転数・BIG回数・REG回数・ぶどう回数）を入力すると、
ポアソン分布に基づくベイズ推定で設定1〜6の期待度（事後確率）を算出するアプリです。

## 対応機種
- マイジャグラーV
- ネオアイムジャグラーEX（2025年9月導入・旧アイムジャグラーEXの後継機）
- ファンキージャグラー2
- ハッピージャグラーV3
- ゴーゴージャグラー3
- ミスタージャグラー
- ジャグラーガールズSS（2024年5月導入・無印「ジャグラーガールズ」の現行後継機）

`app/src/main/java/com/example/jugglersettei/data/JugglerModels.kt` に機種と設定ごとの
BIG/REG/ぶどう確率（分母）をまとめています。他機種の追加や数値の調整もここを編集するだけです。
数値は解析サイト「スロベース」等に掲載されている実機データを参照しています（2026年8月時点）。

> ⚠️ ジャグラーシリーズはボーナス確率以外の小役確率がメーカー非公表の機種が多いため、
> ぶどう確率は解析サイトの推定値(アプリによる大規模シミュレート値や、実戦値からの逆算値)を
> 参照しています。全7機種とも設定判別にぶどうを使用しますが、ネオアイムジャグラーEX・
> ジャグラーガールズSSは設定1〜5(または1〜4)が共通値で高設定のみ優遇される形のため、
> 「ぶどうが良ければ高設定寄り」程度の判別材料になります。
> ホールの個体差・調査ソースにより実機の数値と差異が生じる場合があるため、
> 判別結果は統計的な「目安」であり、設定を保証するものではありません。

## 判別ロジック
`logic/SettingEstimator.kt` にて、各設定における BIG・REG（・ぶどう）の出現回数を
「総回転数 × 出現確率」を期待値とするポアソン分布とみなし、対数尤度を算出。
事前分布を一様（設定1〜6が等確率）としてベイズの定理で事後確率を計算し、正規化して
「設定●の可能性は◯%」という形で表示します。

## ビルド方法
1. [Android Studio](https://developer.android.com/studio)（Koala 以降推奨）をインストール
2. このフォルダ (`JugglerSettei/`) を「Open」で開く
3. Gradle Sync が自動的に走り、必要な Gradle Wrapper 本体（jar）も自動生成されます
   （このプロジェクトには `gradle-wrapper.properties` のみ同梱し、jar 本体はネットワーク環境の都合で
   含めていません。Android Studio で開けば自動的に取得されます）
4. 実機 or エミュレータで実行（▶ボタン）

コマンドラインでビルドする場合は、事前に `gradle wrapper` を一度実行して wrapper jar を生成してください。

```bash
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
```

## 使い方
1. 上部のドロップダウンで機種を選択
2. 総回転数・BIG回数・REG回数を入力（ぶどう回数は分かる場合のみ任意入力）
3. 「設定を判別する」をタップ
4. 設定1〜6ごとの期待度がバーグラフで表示されます
5. 「◯◯の設定判別要素表を見る」から、その機種の設定差（BIG/REG/ぶどう確率）を一覧確認できます
